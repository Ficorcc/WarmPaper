## 一、一个被忽略很久的数字

最近看到一组数据，心里咯噔了一下。WordPress 在全球网站中的占比，第一次跌破了 40%——从去年的 43.2% 一路下滑到现在的 38.6%，而且还在继续往下掉。这个数字背后藏着一个很有意思的趋势：虽然它仍然是第一大内容管理系统，可它的统治力正在被一点点蚕食。更值得关注的是，同期"没有识别出任何 CMS"的网站比例从 28.6% 上升到了 32.9%。也就是说，越来越多的网站正在脱离传统的内容管理系统，走向一种全新的形态。

很多人可能觉得，WordPress 跌几个百分点而已，有什么好大惊小怪的？但在我看来，这不仅仅是数字游戏，而是整个建站生态正在经历一次深刻的重构。过去十年里，我们习惯了用 WordPress 搭建一切——个人博客、企业官网、甚至小型电商网站。但现在，这个习惯正在被打破。

## 二、为什么大家都在离开 WordPress

让我觉得最有意思的是，这次迁移潮的主力不是大公司，而是小团队和个人站长。据商业爬虫统计的数据，从五月底到十一月初，有超过两万两千个域名从 WordPress 迁到了 Astro，而反向迁移的只有两千多个。在这两万多迁移者中，有将近七成是一到十人的小企业或独立开发者。这说明什么？说明真正推动这场变革的，是那些每天在一线写代码、做产品的人，而不是坐在办公室里拍脑袋的决策者。

他们为什么选择离开？原因其实很简单：性能和安全。HTTP Archive 的数据显示，Astro 站点移动端全量核心网页指标通过率达到了 72.2%，而 WordPress 只有 49%；首字节时间良好率更是 64.2% 对 23.5% 的巨大差距。对于一个追求速度的独立站长来说，这种差距不是一般的大。再加上 WordPress 在过去一年里发布了八次安全更新，其中七次集中在下半年，CISA 还新增了四个已知利用漏洞目录，这让很多站长不得不重新审视自己的技术栈。

## 三、Astro 真的那么完美吗

当然，我也得保持一点清醒。Astro 并不是什么银弹，它有自己明显的问题。首先，它对非技术人员不太友好——如果你不懂 Markdown、不会配置构建流程，那 Astro 对你来说就是一堆看不懂的配置文件。其次，Astro 的生态还在成长期，很多插件和主题的选择远不如 WordPress 丰富。最后，也是最关键的一点：Astro 的静态特性意味着你的网站更新需要重新构建部署，这对于需要频繁更新内容的媒体类站点来说是个不小的负担。

所以我的建议是，不要盲目跟风。如果你的网站主要是展示性质的，比如作品集、个人主页、产品介绍页，那 Astro 确实是个不错的选择；但如果你的网站需要复杂的交互功能、会员系统或者实时内容更新，那 WordPress 仍然是更安全务实的选择。毕竟，工具再好也需要有人来维护，选错了代价可不小。

## 四、混合架构成为新热点

让我觉得最有意思的是，现在出现了一种新的趋势：把 WordPress 当作后端、Astro 当作前端。简单来说，就是用 WordPress 来管理内容和排程，然后通过 API 暴露给 Astro 去渲染成静态页面。这种做法的好处很明显：既保留了 WordPress 强大的内容管理能力，又享受了 Astro 极致的加载速度。当然，坑也不少——比如 WordPress 自带的伪定时任务在无头架构下不会触发，必须手动配置系统定时任务；还有远程图片需要在导入时本地化，否则会出现热链失效的问题。

这种混合方案的出现，说明大家已经不再满足于非此即彼的二选一了。与其纠结于"到底该用哪个"，不如思考"怎么组合使用才能发挥各自的优势"。这对我们来说是一个很好的启示：技术的进步往往不是淘汰旧工具，而是让新旧工具更好地协作。

## 五、写在最后

WordPress 跌破 40% 只是一个开始，而不是终点。对于独立站长来说，这意味着我们拥有了更多选择的可能，但也意味着我们需要更加谨慎地做出决定。毕竟，再快的速度也救不了空洞的内容，再先进的框架也填不平质量的鸿沟。

我认为，未来最有价值的不是那些只会追逐新技术的人，也不是那些固守老一套的人，而是懂得根据实际需求灵活组合各种工具的人。至于 WordPress 会不会彻底被淘汰？我的看法是：不会。它会慢慢变成一个更专业的选项，就像当年从 HTML 到 CMS 的转变一样——不是消失，而是进化。
